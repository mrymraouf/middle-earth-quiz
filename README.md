# آزمون سرزمین میانه

## اجرا
Node.js 20+ و PostgreSQL لازم است. متغیرهای `DATABASE_URL`، `ADMIN_PASSWORD` و `SESSION_SECRET` را تنظیم کنید و `npm install && npm start` را اجرا کنید.

## انتشار
فایل `render.yaml` برای ساخت Web Service و PostgreSQL رایگان Render آماده شده است. پنل مدیر در `/admin.html` و آزمون در ریشه سایت است.

## منطق تخصیص
امتیاز مخفی وارثان از ۰ تا ۱۰ محاسبه می‌شود: ۹ و ۱۰ با احتمال اولیه ۱۰۰٪ وارث، ۶ تا ۸ با ۷۰٪ وارث، ۵ با ۵۰٪، و ۰ تا ۴ با ۳۰٪ وارث. اگر دو جبهه برابر باشند این احتمال اعمال می‌شود؛ اگر یکی جلو باشد، نفر بعدی به جبهه عقب‌مانده می‌رود. تخصیص در تراکنش PostgreSQL و با قفل advisory انجام می‌شود تا درخواست‌های هم‌زمان هم توازن را نشکنند. در تعداد زوج، نتیجه نهایی دقیقاً نصف‌نصف است؛ در تعداد فرد اختلاف یک نفر می‌ماند.

## محدودیت پلن رایگان Render
وب‌سرویس رایگان پس از ۱۵ دقیقه بی‌درخواستی خاموش می‌شود و فایل‌های محلی آن پایدار نیستند. PostgreSQL رایگان ۱ گیگابایت است و ۳۰ روز پس از ایجاد منقضی می‌شود؛ برای نگهداری دائمی نتایج باید پیش از انقضا ارتقا دهید یا از داده‌ها خروجی بگیرید.
